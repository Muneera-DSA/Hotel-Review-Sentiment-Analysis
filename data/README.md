# Dataset

The hotel review dataset is not stored directly in this repository because of its large file size.

Download the dataset from Kaggle:

https://www.kaggle.com/datasets/jiasheliu/515k-hotel-reviews-data-in-europe

After downloading, place the CSV file in this folder and rename it:

`hotel_reviews.csv`

The expected local path is:

`data/hotel_reviews.csv`
